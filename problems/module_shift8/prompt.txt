Create a 3-stage shift register using three 8-bit D flip-flops (my_dff8). The 2-bit sel signal selects the number of clock cycles of delay applied to the input d before it appears at output q: 0 cycles (q = d), 1 cycle (q = first flip-flop output), 2 cycles (q = second flip-flop output), or 3 cycles (q = third flip-flop output). The provided my_dff8 module is a positive-edge-triggered D flip-flop with 8-bit data input and output.
