Build a 32-bit adder-subtractor from two provided 16-bit adders (add16). top_module takes 32-bit inputs a and b and a 1-bit input sub. When sub is 0, sum is a + b. When sub is 1, sum is a - b. Do not use the minus operator: in two's complement, a - b equals a + ~b + 1, so the same adders can also subtract if b is inverted and an extra 1 is added. Any carry out of bit 31 is discarded.
